# โจทย์ NF-02: หลายเหตุการณ์ หรือการโจมตีเดียวกัน?

ทีมเฝ้าระวังมี log จากหลายระบบ และตั้งสมมติฐานว่า **C2 → Exfiltration → Lateral Movement** อาจเป็นลำดับการโจมตีเดียวกัน ให้ใช้ Spark วิเคราะห์ [log เพิ่มเติมทั้ง 11 ชุด](EVIDENCE.md) เพื่อพิสูจน์หรือหักล้างสมมติฐานนี้ โดยค้นหาเครื่องและเหตุการณ์เอง

1. **แยกเหตุการณ์:** จัดกลุ่มกิจกรรมที่ควรตรวจสอบตามเครื่อง คู่ติดต่อ และเวลา พร้อมอธิบายสัญญาณ C2, การส่งข้อมูลออก หรือการติดต่อกระจายภายในที่พบ
2. **พิสูจน์ความเชื่อมโยง:** กลุ่มใดมีหลักฐานพอจะเชื่อมกัน และกลุ่มใดควรแยกเป็นคนละเหตุการณ์? แสดงข้อมูลที่ใช้จับคู่และข้อขัดแย้ง อย่าเชื่อมเหตุการณ์จากลำดับเวลา ชื่อไฟล์ หรือเลขท้าย IP เพียงอย่างเดียว
3. **จัดลำดับการสืบสวน:** เลือกสามกลุ่มที่ควรตรวจต่อก่อน พร้อมเหตุผล หลักฐานที่ยังขาด และปัญหาใน log ที่อาจทำให้จับคู่หรือนับความรุนแรงผิด

ส่งตารางกลุ่มเหตุการณ์และความสัมพันธ์ พร้อมเวลา IP/พอร์ต ชื่อไฟล์และเลขบรรทัดที่รองรับ แนบโค้ด Spark, job ID และผลรันจริง แยกสิ่งที่ยืนยันได้ออกจากสมมติฐาน

ใช้เฉพาะไฟล์และ hashes ในรายการหลักฐาน ไม่ใช้เฉลยหรือผลวิเคราะห์เก่า ไม่แก้ไขต้นฉบับ **การสรุปว่ายังเชื่อมเป็นการโจมตีเดียวกันไม่ได้ เป็นคำตอบที่ยอมรับได้เมื่อมีหลักฐานรองรับ**
