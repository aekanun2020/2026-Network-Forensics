# โจทย์ — 10.70.0.66

[สารบัญโจทย์](README.md) · [ดาวน์โหลดหลักฐาน](evidence/README.md)

## คำถามต้นฉบับ

ตรวจสอบกิจกรรมของ **10.70.0.66** จากหลักฐานทั้งหกไฟล์ ระบุว่าติดต่อกับใคร มีพฤติกรรมอะไรเกิดขึ้นตามลำดับเวลา มีข้อมูลส่งออกและการติดต่อเครื่องภายในอย่างไร พร้อมอ้าง records/packets และแยกสิ่งที่ยืนยันได้ออกจากข้อสงสัย

## วิธีทำตามคำขอในบทสนทนา

ใช้ Codex สืบค้นผ่าน MCP server for Spark ที่พอร์ต 8001 แล้วเก็บคำตอบต้นฉบับไว้ จากนั้นให้ Codex ตรวจคำตอบจากไฟล์โดยตรง **โดยไม่ใช้ MCP** ในรอบ cross-check โปรแกรมช่วยคำนวณ hashes, counts และ joins ได้ แต่ Codex ต้องประเมินความหมายของคำตอบเอง

HDFS physical directory ของหลักฐานในสภาพแวดล้อมต้นทางคือ `/mcp/student/agentic-siem/incident-lab/input/`; virtual directory ที่ tools ใช้คือ `/student/agentic-siem/incident-lab/input/` อย่าสันนิษฐานว่า localhost ของเครื่องผู้เรียนคือ server เดียวกัน ให้ใช้ endpoint ที่ผู้สอนยืนยัน

ไฟล์ ZIP หกไฟล์อยู่ใน [evidence/](evidence/README.md) ภายหลังแตก ZIP ใช้ชื่อ member ตาม manifest เลข record นับจากบรรทัดแรกเป็น 1; packet นับจากต้น PCAP เป็น 1 ใช้เวลา UTC และอธิบายว่ารายงานเวลาเริ่ม connection หรือเวลา packet

ส่งคำตอบที่มีคู่ติดต่อ ลำดับเหตุการณ์ ทิศทาง/ปริมาณข้อมูล การติดต่อภายใน และข้อจำกัด พร้อมอ้าง filename + record/packet เก็บคำตอบเดิมกับผลตรวจแยกกัน แล้วจึงเปิด [เฉลย](REFERENCE-ANSWER.md)
